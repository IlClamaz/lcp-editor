Source code doesn't work. Need to clone the project and init submodules.

```
#  to fetch ffmpeg-kit sources.
git submodule update --init
make bootstrap 
# For universal build
make gdextension PLATFORM=macos TARGET_ARCH="arm64 x86_64"
```

```
brew install scons
``` 

 Confirmed. Run the ffmpeg-kit build directly for x86_64 only (arm64 is already done and will be skipped):
                                                                                                                                       
cd ffmpeg-kit && ./macos.sh --target=10.12 --disable-arm64 --enable-gpl --enable-macos-avfoundation --no-framework --enable-x264  --enable-x265 --enable-lame
                  
  Once that finishes, resume with:                                                                                                     
                  
  make gdextension PLATFORM=macos TARGET_ARCH="arm64 x86_64"                                                                           
                                                                                                                                       
  The --disable-arm64 flag tells ffmpeg-kit to skip arm64 and only build x86_64, so you won't be rebuilding what's already done.
